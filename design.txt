THINK-BUS DESIGN SYSTEM - SPECIFICATIONS
==========================================

This document serves as the master design reference for the THINK-BUS project. 
It captures the "Neumorphic Soft UI" aesthetic (v3.1 - Refined Definition).

1. DESIGN PHILOSOPHY
--------------------
Style: Neumorphic Soft UI (Material Realism with Edge Definition)
Character: Tactile, clean, premium, and calm.
Key Features: Physical depth created via light and shadow, extruded surfaces (raised), 
inset states (pressed), and a consistent monochromatic base with vibrant accents.
Update (v3.1): Added subtle 1px borders to grounded elements for sharpened edge definition.

2. COLOR PALETTE
----------------
The system uses CSS variables for theme-aware coloring.

2.1 Dark Mode (Modern Slate - Default)
- Background Main:   #0f172a (Primary surface)
- Primary Color:     #3b82f6 (Blue 500)
- Secondary Color:   #8b5cf6 (Violet 500)
- Text Primary:      #f1f5f9
- Text Secondary:    #94a3b8
- Shadows:           6px 6px 14px rgba(0, 0, 0, 0.8), 
                     -6px -6px 14px rgba(255, 255, 255, 0.05)
- Border Subtle:     rgba(255, 255, 255, 0.05)

2.2 Light Mode (Refined Pearl)
- Background Main:   #ebf0f5 (Slightly deeper for highlight contrast)
- Primary Color:     #2563eb (Blue 600)
- Secondary Color:   #7c3aed (Violet 600)
- Text Primary:      #0f172a
- Text Secondary:    #475569
- Shadows:           7px 7px 18px rgba(15, 23, 42, 0.18), 
                     -7px -7px 18px #ffffff
- Border Subtle:     rgba(0, 0, 0, 0.05)

3. NEUMORPHIC PROPERTIES
---------------------------
To achieve the 'Soft UI' effect, use the following variables:

3.1 Extruded Surface (Raised)
- Box Shadow:        var(--neu-shadow)
- Background:        var(--bg-main)
- Border:            1px solid var(--border-subtle) (Added in v3.1)
- Transition:        0.3s cubic-bezier(0.4, 0, 0.2, 1)

3.2 Inset Surface (Pressed/Selected)
- Box Shadow:        var(--neu-shadow-inset)
- Background:        var(--bg-main)
- Border:            1px solid var(--border-subtle)

4. TYPOGRAPHY
-------------
- Font Family:       "Outfit", "Inter", sans-serif (Google Fonts)
- Base Size:         16px
- Smoothing:         Antialiased

5. CORE UI COMPONENTS
---------------------
5.1 NeumorphicCard
- Background:        var(--bg-main).
- Rounded corners:   16px - 24px (Large radius).
- Depth:             Extruded shadow.
- Borders:           1px solid var(--border-subtle).

5.2 ActionButtons (Neumorphic)
- Rounded corners:   12px.
- Weight:            700 (Bold).
- Resting State:     Extruded surface.
- Active/Focus:      Inset shadow (physical press).
- Alignment:         Center icons/text for better tactile feedback.

5.3 Global Layout (Header & Sidebar)
- Header:            border-bottom: 1px solid var(--border-subtle).
- Sidebar:           border-right: 1px solid var(--border-subtle).
- Active Link:       Inset shadow (creates a 'depressed' physical state).

6. INTERACTION & ANIMATION
--------------------------
- Transitions:       0.3s ease for depth shifts (Raised -> Inset).
- Page Entrance:     0.5s ease-out 'fadeInSlide'.
- Interactive Cues:  Subtle scale down (0.98) on active states to enhance physical feel.

7. IMPLEMENTATION NOTES
-----------------------
- Global theme is controlled via [data-theme="light"] attribute on <html>.
- Avoid using 'backdrop-filter' or high-opacity overlays.
- Physical logic: Lights come from top-left, shadows fall to bottom-right.
- Always use CSS variables instead of hardcoded hex values.
